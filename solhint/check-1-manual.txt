    How to execute SolHint.

Run the wrapper from the solhint directory. It uses Linux utilities, including gio trash.
Alternatively, from the repository root run:

   HARDHAT_MODE_CODE=1 ENABLE_HARDHAT_PREPROCESSOR=false npx hardhat check

This checks lint rules, not runtime correctness or formal verification. Preserve the full
report before filtering display output so suppressed warnings remain available for review.

@ If necessary, edit `../.solhint.json`.

@ Execute `./check-1.bash`.

@ After the script finishes, review its report file, which name is specified near Comment-202409124.

@ Use a reg-exp pattern like this to remove lines from the report file:

^.*? (?:no-empty-blocks|gas-multitoken1155|ordering|no-inline-assembly|max-states-count)\n
^.*? (?:gas-custom-errors|comprehensive-interface)\n

@ An alternative option is to execute the following command in the VS Code integrated terminal:

   npx hardhat check

   Then use Ctrl+Click to click links in the command output.
